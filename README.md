<h1>Overview</h1>
This project is a small TFT using a Raspberry Pi Pico 2 to take text from a SD card and allow the user go through the text.

<h2>Additional Information</h2>
The code for the project is written in circuit python, and has been commented out to help users modify it.
The .gerber files are also included as well.
